CNN-LSTM Neural Network Architecture
  • 1D Convolutional Layers (Conv1D): Extract spatial harmonics, high-frequency impact peaks, and local shape features from multi-channel sensor windows.
  • Batch Normalization & Max Pooling: Stabilizes gradient updates during backpropagation and reduces feature map spatial dimensionality.
  • Long Short-Term Memory (LSTM): Captures sequence degradation dynamics and long-term temporal dependencies across sliding time steps.
  • Dense & Softmax Classifier: Computes probability vector mapping to discrete bearing/machine fault conditions.
Primary Dataset & Academic Scope
  • CWRU Bearing Dataset: Case Western Reserve University Bearing Data Center vibration signals used for baseline fault classification (Normal, Inner Race, Outer Race, Ball Fault).
  • Generic CSV Compatibility: Flexible preprocessing pipeline dynamically detects numeric columns and label fields for custom machine datasets.
  • Optional RUL Extension: Remaining Useful Life (RUL) regression (e.g. NASA C-MAPSS run-to-failure data) is maintained as a separate optional extension module to avoid mixing classification and regression targets.
  • Software-Only Prototype: Operates entirely via historical CSV datasets without requiring physical microcontrollers (Arduino/Raspberry Pi) or IoT hardware.
